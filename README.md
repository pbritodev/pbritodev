## 🚀 Projeto em destaque

### [🏋️ TreinoCerto](https://github.com/pbritodev/treino-certo)

App Android em **Kotlin** que gera um **plano de treino personalizado** a partir de um questionário e acompanha **calorias**, **peso** e **progresso** do usuário. Ele consome uma **API REST própria** em Node.js + SQLite, documentada com Swagger e publicada na nuvem.

- 17 telas com Material Design 3, tema claro e escuro.
- Login com senha protegida (hash), diário alimentar no estilo contador de calorias, gráfico de peso e registro de treinos.
- Integrações com a agenda, os mapas e o compartilhamento do celular (Intents implícitas).
- API com 39 testes automatizados e [documentação Swagger online](https://treino-certo-api.onrender.com/docs).
